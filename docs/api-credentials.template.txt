events.apptoolstack.com for WordPress -- API credentials
=======================================================

Fill in the four required values below, save this file as
API-CREDENTIALS.txt inside the handoff bundle, and send it to the
customer along with INSTALL.md and the plugin zip.

Treat the secret like a password.

Required
--------

Host URL            : https://events.<district>.org
API key             : <OAuth client ID from events.apptoolstack.com>
Secret              : <OAuth client secret from events.apptoolstack.com>
Group ID            : <numeric group ID; comma-separated only if multiple>

Optional
--------

Category IDs        : <comma-separated numeric category IDs, or leave blank>
Calendar URL        : <path or full URL on THIS WordPress site, e.g. /events>

Where these go in WordPress
---------------------------

Settings -> events.apptoolstack.com
  - Host URL              -> "Host URL"
  - API key               -> "API key"
  - Secret                -> "Secret" (paste, then Save Changes)
  - Group ID              -> "Group ID"
  - Category IDs (opt.)   -> "Category IDs" (global default; can be
                             overridden per widget)
  - Calendar URL (opt.)   -> "Calendar URL" (footer "View Calendar"
                             link; a page on THIS WordPress site)

Click Save Changes, then Test connection.
